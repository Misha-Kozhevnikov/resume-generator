# Генератор резюме

Веб-приложение на Vite и чистом JavaScript для пошагового создания резюме, выбора шаблона под профессию, получения подсказок по улучшению текста и экспорта результата в PDF.

## О проекте

**Цель проекта:**  
Создать удобную интерактивную систему, которая помогает пользователю быстро собрать профессиональное резюме по шагам, получить рекомендации по оформлению и сохранить результат в PDF.

**Целевая аудитория:**
- соискатели;
- студенты;
- специалисты, которые хотят обновить резюме;
- пользователи, которым нужен быстрый и понятный конструктор резюме.

## Возможности

- Пошаговое заполнение резюме.
- Шаблоны под разные профессии.
- Превью резюме в реальном времени.
- Рекомендации по заполнению и ATS-ключам.
- Сохранение черновика в `localStorage`.
- История сохранённых резюме.
- Экспорт в PDF.
- Модальное окно для уведомлений.

## Технологии

- **JavaScript** — основная логика приложения.
- **HTML/CSS** — структура и стили интерфейса.
- **Vite** — сборка и локальный запуск проекта.
- **jsPDF** — генерация PDF.
- **localStorage** — хранение черновика и истории в браузере.

## Установка

### 1. Установите зависимости
```bash
npm install
```

### 2. Запустите проект в режиме разработки
```bash
npm run dev
```

После запуска Vite покажет локальный адрес, обычно это:
- `http://localhost:5173`

### 3. Соберите проект для продакшена
```bash
npm run build
```

### 4. Проверьте сборку локально
```bash
npm run preview
```

## Как пользоваться

1. Откройте сайт в браузере.
2. Заполните личные данные.

## Архитектура приложения

Архитектура проекта модульная и построена по принципу разделения ответственности.

### 1. Слой представления
Отвечает за отображение интерфейса:
- `App.js` формирует HTML-разметку;
- `main.css` отвечает за внешний вид;
- превью резюме отображается отдельно от формы.

### 2. Слой состояния
Отвечает за данные формы:
- текущее состояние хранится в объекте `state`;
- повторяющиеся блоки опыта и образования хранятся в массивах;
- выбранный шаблон хранится отдельно через `templateSelect`.

### 3. Слой логики
Содержит:
- обработку кликов;
- пошаговую навигацию;
- добавление и удаление блоков;
- обновление превью;
- открытие и закрытие модалки;
- сохранение черновика.

### 4. Слой данных
Содержит статические настройки:
- список шаблонов;
- их названия;
- цвета;
- ключевые слова ATS;
- описания.

### 5. Слой хранения
Использует браузерное `localStorage`:
- черновик сохраняется между перезагрузками;
- история сохраняется отдельно;
- пользователь может полностью очистить данные.

## Как работает черновик

Черновик хранится в `localStorage` и обновляется при вводе данных.  
При повторном открытии страницы приложение загружает сохранённое состояние и восстанавливает форму.

Если нажать **Сбросить черновик**, приложение:
- очищает черновик;
- очищает историю;
- сбрасывает состояние формы;
- возвращает первый шаг;
- перерисовывает интерфейс.

## Как работает PDF-экспорт

Экспорт PDF выполняется через `jsPDF`:
- создаётся новый документ;
- в него пишутся данные резюме;
- добавляются разделы;
- файл сохраняется локально на устройство.

Если часть данных не заполнена, PDF всё равно создаётся, но с пустыми или сокращёнными блоками.
